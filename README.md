## 🐙 2. GitHub Profile README

Your `README.md` in your special repository (`username/username`) is your developer landing page. 

**Essential Elements:**
1.  **A strong header:** Include your name, title, and a brief 1-2 sentence mission statement.
2.  **Tech Stack Badges:** Use [Shields.io](https://shields.io/) or [Skill Icons](https://github.com/tandpfun/skill-icons) to visually display your skills.
3.  **Dynamic Stats:** Use [GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats) to show your total commits, PRs, and top languages.
4.  **Current Focus:** A bulleted list of what you are currently learning, building, or looking to collaborate on.

## 💼 3. LinkedIn Optimization

Recruiters search for keywords, but they click on well-presented profiles.

* **The Banner:** Don't leave it blank. Use a banner that reflects your stack (e.g., a subtle code snippet background or a clean gradient).
* **The Headshot:** As mentioned above, use a high-quality **headshot** (try [PFPMaker.ai](https://pfpmaker.ai/)). Profiles with professional headshots get up to 36x more interactions.
* **The Headline:** Formula: `[Role] | [Tech Stack] | [Value Proposition]`. (e.g., *Full Stack Engineer | React & Node.js | Building scalable SaaS apps*).
* **The About Section:** Write in the first person. Tell the story of *why* you code, not just *what* you code.

## 🌐 4. Portfolio Website

A simple, fast portfolio beats a complex, broken one. 

* **Keep it fast:** Use static site generators like Astro, Next.js, or Hugo.
* **Show, don't just tell:** For every project, include a live demo link, a link to the source code, and a 3-bullet summary of the problem you solved.
* **Make it personal:** Include an "About Me" page with your polished **AI headshots** and links to your active social platforms.
